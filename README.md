# Domain Intelligence Tool

Ek comprehensive domain intelligence tool jo WHOIS, DNS records, SSL certificates aur hosting information provide karta hai.

## Features

- WHOIS Lookup
- DNS Records Analysis
- SSL Certificate Information
- Hosting Provider Detection
- ASN Information
- Nameserver Details
- Report Generation aur Export

## Tech Stack

- Frontend: React.js
- Backend: Node.js + Express.js
- Database: PostgreSQL
- Caching: Redis

## Setup Instructions

1. Clone the repository
2. Install dependencies for frontend aur backend
3. Configure environment variables
4. Set up database
5. Run the application

## API Endpoints

- `GET /api/domain/analyze/:domain` - Domain intelligence analyze karta hai
- `GET /api/domain/whois/:domain` - WHOIS information provide karta hai
- `GET /api/domain/dns/:domain` - DNS records provide karta hai
- `GET /api/domain/ssl/:domain` - SSL certificate information provide karta hai
